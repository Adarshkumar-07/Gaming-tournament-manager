# Gaming Tournament Manager

A simple web application that allows users to manage gaming tournament participants.

This project demonstrates basic web development using HTML, CSS, and JavaScript.

---

## Features

- Add players to a tournament
- Dynamic player list generation
- Simple and responsive interface
- Real-time updates using JavaScript

---

## Technologies Used

- HTML
- CSS
- JavaScript

---

## Project Structure

gaming-tournament-manager
│
├── index.html # Main webpage
├── style.css # Styling for the UI
├── script.js # JavaScript logic
└── README.md # Project documentation


---

## How to Run the Project

1. Clone the repository

git clone https://github.com/YOURUSERNAME/gaming-tournament-manager.git

2. Navigate to the project folder

cd gaming-tournament-manager

3. Open the project

Simply open **index.html** in your browser.

OR run a local server

python -m http.server

Then open:

http://localhost:8000


---

## How It Works

1. Enter a player name.
2. Click **Add Player**.
3. The player will appear in the tournament list.
